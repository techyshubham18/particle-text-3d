# 🌌 Particle to 3D Text Animation

An interactive 3D particle network built with **Three.js and GSAP** that transforms thousands of particles into custom text. Type any word and watch the particles smoothly morph from a rotating cosmic sphere into stunning 3D typography.

## ✨ Features

- Dynamic text morphing (up to 20 characters)
- Thousands of animated particles
- Smooth GSAP-powered transitions
- Interactive 3D scene using Three.js
- Automatic reset to rotating particle sphere
- Fully responsive design (desktop + mobile)
- Modern glassmorphic user interface

## 🛠️ Usage

No build step needed. Just clone and open:

```bash
git clone https://github.com/techyshubham18/particle-text-3d.git
cd particle-text-3d
open index.html
```

*(Recommended: Use VS Code Live Server for best performance)*
